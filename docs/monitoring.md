# 监控体系

本文档说明 `monitor/` 目录下的实时监控模块，包括板块监控、市场情绪评分、指标计算与报表生成。

## 一、模块总览

| 文件 | 职责 | 运行方式 |
|------|------|---------|
| `sector_monitor.py` | 板块涨幅 & 资金流向实时监控 | 独立线程 |
| `sentiment.py` | 市场情绪基础指标计算 | 被调度调用 |
| `sentiment_task.py` | 情绪监控调度任务 | 独立线程 |
| `indicators.py` | 综合情绪评分（1-10 分） | 被调度调用 |
| `dashboard.py` | HTML 邮件报表生成 | 被调度调用 |

---

## 二、板块监控 (`sector_monitor.py`)

### 2.1 概念板块回调: `concept_sector_data_callback(df_sectors, shared_data)`

**触发频率**：每 10 秒

**数据源**：东方财富概念板块涨幅数据

**处理流程**：
1. 排除特殊板块（昨日涨停类指数）：BK1051、BK0816、BK0817、BK1050、BK0815
2. 过滤：板块涨幅 ≥ 1.5%
3. 提取每个板块的：板块代码、名称、涨幅、领涨股代码/名称
4. 更新 `shared_data['概念板块效应']`
5. 统计各板块的涨停股数量

### 2.2 行业板块回调: `industry_sector_data_callback(df_sectors, shared_data)`

逻辑与概念板块回调相同，更新 `shared_data['行业板块效应']`。

### 2.3 资金流向回调: `stock_capital_flow_callback(df_stock, shared_data)`

**数据源**：东方财富个股资金流向数据

**过滤条件**（满足任一即标记为"有资金流入"）：
- 涨幅 > 0% 且 主力净流入 > 5000 万 且 主力净流入占比 > 10%
- 涨幅 > 0% 且 超大单净流入 > 3000 万 且 超大单净流入占比 > 5%

**处理**：更新 `shared_data['个股资金流入']` 列表。

### 2.4 板块与资金流监控主循环: `sector_and_capitalflow_monitor_task(shared_data)`

```python
while True:
    # 每 10 秒
    fetch_concept_sectors() → concept_sector_data_callback()
    fetch_industry_sectors() → industry_sector_data_callback()
    fetch_capital_flow() → stock_capital_flow_callback()

    # 每 60 秒
    检查观察名单自动释放:
        for stock in 观察名单:
            if 加入时间 > 30 分钟前:
                移出观察名单
```

### 2.5 同花顺监控: `ths_monitor_task(shared_data)`

**功能**：抓取同花顺的昨日涨停和首板股票实时 Tick 数据，计算平均涨幅。

**输出**：
- `shared_data['市场情绪_昨日涨停表现']` — 昨日涨停股今日平均涨幅
- `shared_data['市场情绪_昨日首板表现']` — 昨日首板股今日平均涨幅

## 三、市场情绪计算 (`sentiment.py`)

### 3.1 `calculate_market_sentiment_metrics(shared_data)`

**功能**：计算市场情绪的基础指标。

**计算内容**：

1. **涨停板统计**
   - 遍历 `shared_data['涨停池']`
   - 排除炸板（状态 ≠ LIMIT_UP）
   - 更新 `市场情绪_涨停板数量` 和 `市场情绪_炸板数量`
   - 计算 `市场情绪_炸板率` = 炸板数 / (涨停数 + 炸板数)

2. **大盘指数**
   - 查询四大指数最新价：
     - 000001.SH (上证指数)
     - 000300.SH (沪深 300)
     - 399006.SZ (创业板指)
     - 399001.SZ (深证成指)
   - 计算涨跌幅 = (最新价 - 昨收) / 昨收 × 100%

3. **昨日涨停延续**
   - 统计昨日首板/涨停股的今日表现（通过同花顺数据）

## 四、综合情绪评分 (`indicators.py`)

### 4.1 `log_key_market_indicators(shared_data)`

**功能**：将多项基础指标综合计算为 **1-10 分**的市场情绪评分。

**评分模型**（基准分 5.0）：

#### 因子 1：涨停板数量 (±1.5 分)

| 涨停数 | 加减分 | 市场含义 |
|--------|--------|---------|
| ≥ 80 | +1.5 | 市场极度活跃 |
| ≥ 60 | +1.2 | 市场活跃 |
| ≥ 40 | +0.8 | 市场正常偏强 |
| ≥ 20 | +0.4 | 市场一般 |
| 10-19 | 0 | 市场低迷 |
| < 10 | -0.8 | 市场极度低迷 |

#### 因子 2：炸板率 (±1.5 分)

尚无股票触及涨停时，炸板率为 `0/0`，该因子按中性处理；不会把无样本的
`0%` 误判为封板质量极高。

| 炸板率 | 加减分 | 市场含义 |
|--------|--------|---------|
| ≤ 20% | +1.5 | 封板质量极高 |
| ≤ 30% | +0.8 | 封板质量良好 |
| ≤ 50% | 0 | 正常 |
| ≤ 70% | -0.8 | 封板困难 |
| > 70% | -1.5 | 大面积炸板 |

#### 因子 3：昨日涨停延续率 (±1.2 分)

| 延续率 | 加减分 | 含义 |
|--------|--------|------|
| ≥ 40% | +1.2 | 赚钱效应强 |
| ≥ 30% | +0.8 | 赚钱效应良好 |
| ≥ 20% | +0.4 | 正常 |
| 10%-19% | 0 | 赚钱效应弱 |
| < 10% | -0.6 | 亏钱效应 |

#### 因子 4：昨日表现 (±1.0 分)

综合昨日首板和涨停股的平均涨幅。
输入单位为百分数点（`3.0` 表示 `+3%`），评分阈值为 `+1/+3` 和 `-1/-3`
个百分点。市场指数和昨日涨停表现快照超过 30 秒时不刷新评分；买入端同样拒绝
使用超过 30 秒的情绪分数。

#### 因子 5：大盘指数 (±1.0 分)

四大指数涨跌幅的算术平均。

#### 因子 6：指数分歧度 (±0.3 分)

四大指数涨跌幅的标准差。分歧越大扣分越多。

**最终评分**：`clamp(base + 因子1 + 因子2 + ... + 因子6, 1, 10)`

### 4.2 评分等级映射

| 评分范围 | 情绪等级 | 操作建议 |
|---------|---------|---------|
| ≥ 8.0 | 极强 | 积极扫板和排板，封单门槛最低 |
| ≥ 7.0 | 强势 | 正常排板，适度扫板 |
| ≥ 5.5 | 中性偏强 | 排板精选；扫板须满足动态板块/领涨共振 |
| ≥ 4.0 | 中性 | 排板提高封单门槛；扫板须满足更严格共振 |
| ≥ 2.5 | 弱势 | 仅排板，封单要求高 |
| < 2.5 | 极弱 | 空仓等待 |

### 4.3 评分变化告警

当评分变化幅度 ≥ 1.0 分时，自动发送邮件告警。

## 五、情绪监控调度 (`sentiment_task.py`)

### 5.1 `market_sentiment_monitor_task_manual(shared_data)`

**功能**：手动时间控制的情绪监控主循环（替代 `schedule` 库版本）。

**调度频率**：

| 任务 | 频率 | 功能 |
|------|------|------|
| 情绪指标计算 | 每 3 秒 | 涨停数/炸板数/大盘指数更新 |
| 同花顺监控 | 每 3 秒 | 昨日涨停/首板表现更新 |
| 综合评分 | 每 5 秒 | 计算 1-10 分评分 |
| HTML 报表邮件 | 每 5 分钟 | 发送完整市场状态报表 |
| 心跳日志 | 每 60 秒 | 打印监控线程存活标记 |

**安全封装**：每个子任务都有 60 秒超时保护 + XTData 重连机制。

## 六、HTML 报表 (`dashboard.py`)

### 6.1 `log_market_sentiment_summary_email(shared_data)`

**功能**：生成并发送 HTML 格式的市场状态邮件报表。

**报表内容**（约 1000 行 HTML）：

#### Section 1: 市场情绪总览
- 情绪评分大卡片（颜色梯度：绿→黄→红）
- 涨停数 / 炸板数 / 炸板率
- 四大指数涨跌幅

#### Section 2: 持仓状态
- 表格：股票代码、名称、持仓量、成本价、最新价、盈亏%

#### Section 3: 委托状态
- 表格：委托代码、方向、价格、数量、状态

#### Section 4: 涨停池分析
- 当前封死涨停的股票列表
- 封单金额、首次涨停时间、炸板次数

#### Section 5: 概念板块 TOP 10
- 板块名称、涨幅、领涨股

#### Section 6: 行业板块 TOP 10
- 同上

#### Section 7: 资金流入 TOP 20
- 按主力净流入排序

#### Section 8: 黑名单详情
- 被加入黑名单的股票及原因

#### Section 9: 策略统计
- 撤单次数、黑名单数量、观察名单数量

#### Section 10: 策略建议
- 基于评分的操作建议文案

**样式特点**：
- 渐变背景色基于情绪评分
- 粘性表头（sticky header）支持滚动
- 盈亏用红/绿色区分
- 响应式布局
