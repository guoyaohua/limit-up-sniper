# 东方财富涨停板/炸板数据解析器

## 功能说明

该脚本用于解析东方财富网涨停板行情页面保存的 mhtml 文件，提取涨停股票和炸板股票数据，并将结果分类保存到文本文件中。

## 主要功能

1. **解析涨停数据**：从涨停列表中提取股票信息
   - 自动分类为首板和连板股票
   - 首板：涨停统计中涨停次数为1次的股票
   - 连板：涨停统计中涨停次数≥2次的股票

2. **解析炸板数据**：从炸板列表中提取曾经封板但后来打开的股票

3. **股票代码处理**：自动添加正确的交易所后缀
   - `.SH`：上海主板、科创板（60xxxx, 688xxx）
   - `.SZ`：深圳主板、中小板、创业板（000xxx, 001xxx, 002xxx, 003xxx, 300xxx, 301xxx）
   - `.BJ`：北京证券交易所（8xxxxx, 4xxxxx, 920xxx）

## 使用方法

### 1. 准备输入文件

将从东方财富网涨停板页面保存的 mhtml 文件放置在 `output/dfcf_ztlb/` 目录下，文件命名格式：
- 涨停数据：`涨停_YYYYMMDD.mhtml`
- 炸板数据：`炸板_YYYYMMDD.mhtml`

例如：
```
output/dfcf_ztlb/涨停_20251113.mhtml
output/dfcf_ztlb/炸板_20251113.mhtml
```

### 2. 运行脚本

```bash
python scraper/dfcf_ztlb_parser.py
```

### 3. 查看输出结果

脚本会在 `output/涨停列表/` 目录下生成以下文件：
- `首次涨停_YYYYMMDD.txt`：首板涨停股票列表
- `涨停_YYYYMMDD.txt`：连板涨停股票列表
- `炸板_YYYYMMDD.txt`：炸板股票列表

## 输出文件格式

每个输出文件仅包含股票代码列表，每行一个股票代码（含交易所后缀）：

```
002083.SZ
000407.SZ
003041.SZ
600829.SH
600429.SH
920252.BJ
```

格式说明：
- 每行一个股票代码
- 股票代码包含交易所后缀（.SH/.SZ/.BJ）
- 无其他额外信息
- 纯文本格式，方便程序读取

## 分类逻辑

### 涨停股票分类

1. **连板股票**：涨停统计显示涨停次数 ≥ 2次
2. **首板股票**：涨停统计显示涨停次数 = 1次，或者近期首次涨停

### 炸板股票

所有在盘中触及涨停但未能封住的股票

## 技术细节

### mhtml 文件解析

- 自动解码 quoted-printable 编码
- 使用 BeautifulSoup 解析 HTML 结构
- 提取 `<tr>` 标签中的 `data-stockcode`、`data-stockname` 等属性

### 数据提取

从每个股票行中提取：
- 基本信息：代码、名称、市场
- 价格信息：涨跌幅、最新价
- 封板信息：首次封板时间、炸板次数
- 连板信息：涨停统计（n/m 格式）
- 其他信息：所属行业

## 注意事项

1. 确保 mhtml 文件格式正确，从东方财富网涨停板页面保存
2. 文件名必须符合命名规范：`涨停_YYYYMMDD.mhtml` 或 `炸板_YYYYMMDD.mhtml`
3. 输出目录会自动创建，无需手动创建
4. 股票代码后缀根据股票代码前缀自动判断，优先级高于市场参数

## 常见问题

### Q: 为什么有些股票被分类为首板？
A: 涨停统计中显示该股票在统计周期内只有1次涨停，或者是近期首次涨停。

### Q: 股票代码后缀如何确定？
A: 优先根据股票代码前缀判断（如60xxxx为上海主板），其次根据市场参数（0=深圳，1=上海）。

### Q: 为什么解析的股票数量与网页显示不一致？
A: 可能是网页动态加载了部分内容，或者保存 mhtml 时未完全加载。建议等待页面完全加载后再保存。
